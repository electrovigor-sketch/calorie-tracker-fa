# کالری‌یار

یک وب‌اپ فارسی راست‌چین و قابل نصب روی گوشی (PWA) برای ثبت کالری، درشت‌مغذی‌ها، وزن، ورزش، آب و برنامه غذایی؛ با دو پروفایل مستقل روی همان مرورگر.

## انتشار روی GitHub Pages
1. در GitHub یک repository جدید بساز. برای ساده‌تر بودن، `Public` را انتخاب کن.
2. همه فایل‌های این پوشه (`index.html`, `manifest.json`, `service-worker.js`, `icon.svg`, `README.md`) را مستقیماً در ریشه مخزن بارگذاری کن، نه داخل یک پوشه دیگر.
3. وارد `Settings` مخزن شو و از بخش `Pages`، گزینه `Deploy from a branch` را انتخاب کن.
4. شاخه `main` و پوشه `/(root)` را انتخاب و `Save` کن.
5. چند دقیقه صبر کن و آدرس `https://USERNAME.github.io/REPOSITORY/` را باز کن.
6. در Chrome اندروید، منوی سه‌نقطه را باز کن و `Install app` یا `Add to Home screen` را بزن.

## اطلاعات و پشتیبان
- داده‌ها در `localStorage` مرورگر همان دستگاه ذخیره می‌شوند؛ این نسخه همگام‌سازی ابری یا ورود امن چنددستگاهی ندارد.
- از بخش «پروفایل و پشتیبان» مرتب خروجی JSON بگیر.
- اگر داده‌های مرورگر پاک شوند، ممکن است اطلاعات برنامه از بین بروند.
- آیکون برنامه داخل `icon.svg` است و در `manifest.json` معرفی شده است.

## نکته سلامت
بانک خوراکی شامل نمونه‌های عمومی است و اعداد ممکن است با برند، دستور پخت و اندازه واقعی متفاوت باشند. هدف کالری و کالری‌سوزی ورزش تخمینی‌اند و جایگزین نظر پزشک یا متخصص تغذیه نیستند.
